# Piscine Deep Learning & IA — Python

Troisième piscine, après [Python](https://github.com/lsoulier42/piscine_python) et [Machine Learning](https://github.com/lsoulier42/piscine_machine_learning). Projet original inspiré de la pédagogie 42, non affilié à l'École 42.

## Objectif
Comprendre le deep learning et les architectures modernes d'IA par l'implémentation et l'expérimentation, sans dépendre d'une API de modèle opaque.

## Méthode
- Exercices progressifs `ex00`, `ex01`… ; aucun corrigé.
- Construire les mécanismes fondamentaux avant d'utiliser les abstractions PyTorch.
- Travailler sur des jeux de données réduits et des modèles entraînables sans GPU obligatoire.
- Mesurer les performances, garder un jeu de validation et rendre les expériences reproductibles.

## Environnement
Python 3.11+ ; NumPy et PyTorch introduits progressivement, puis bibliothèques spécialisées selon les sujets.
